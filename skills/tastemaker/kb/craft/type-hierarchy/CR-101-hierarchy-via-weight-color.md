# Hierarchy via Weight & Color, Not Just Size

## Rule
Build typographic hierarchy with **three levers — size, weight, and color (or opacity)** — not size alone. Most hierarchy problems are solved by making secondary text lighter in *weight* and *color* rather than just smaller. A primary line in a heavier weight and darker color; supporting text in regular weight and a muted gray.

## Why it matters
Designers reaching only for size produce either too many sizes (a ladder of 6–8 steps, CR-102) or weak contrast between levels. Weight and color do hierarchy work that size can't: they let two pieces of text at the *same* size read as clearly primary and secondary. This is the single highest-leverage move in type — it's how you get rich hierarchy from a small set of sizes.

## How to spot it
Look at a label-value or title-subtitle pair. Is the distinction carried only by size? If secondary text is just "smaller" but the same weight and color as primary, the hierarchy is thin. Strong hierarchy shows clear weight *and* color steps, often with minimal size difference.

## The fix
Demote secondary text by weight and color, not (only) size: drop it to regular weight and a muted gray (e.g. a 60% text color). Promote primary by weight (medium/semibold) and a near-black. Reserve large size jumps for genuine display moments.

## Eye-training
Try designing a screen with only *one or two* font sizes, forcing yourself to create hierarchy with weight and color. You'll discover how much range those two levers have. After that, "make it bigger" stops being your reflex for "make it more important."

## When to flex
Genuine display type (a hero headline, a hero number) legitimately uses large size as the dominant lever — there, size *is* the move. The rule guards against using size as the *only* lever throughout the interface.
